# Security policy

## Reporting a vulnerability

Email **support@webcrawlerapi.com** with the subject "Security report: MCP server". Please include:

- what you found and where (endpoint, request, or file)
- steps to reproduce
- the impact you expect

Do not open a public issue for security problems. We aim to reply within 3 business days and will keep you updated
until the issue is fixed.

## Scope

This repository is the WebCrawlerAPI remote MCP server (`https://mcp.webcrawlerapi.com/mcp`). Authorization is handled
by `https://auth.webcrawlerapi.com`. Reports about either are welcome.

Please do not run load tests or automated scanners against production, and do not access data that is not yours.
